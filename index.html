Stopwatches are saved automatically in this browser (local storage) — even if the page is closed, refreshed, or the browser crashes, it will continue from where you left off.
Note: using a different browser, incognito tab, or clearing cache will reset the saved data; if multiple tabs are open at the same time, the one that saves last wins.
Only one stopwatch runs at a time: starting one automatically pauses the rest. The goal you set in the header applies to every stopwatch, and each one pings once when it reaches that goal. Taking a lap restarts both the goal bar and the reminder countdown from that point.
Notifications: a running stopwatch pings at the interval you pick; a paused one pings once if it is not restarted within that same interval. Starting, pausing, resetting, or changing the interval restarts the countdown. A stopwatch sitting at 00:00 never triggers anything, and the tab must stay open.
